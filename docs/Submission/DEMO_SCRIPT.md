14. Logout.
15. Login as Doctor.
16. Open My Appointments.
17. Open assigned appointment.
18. Start consultation.
19. Enter symptoms, diagnosis and notes.
20. Save consultation.
21. Show appointment becomes COMPLETED.

23. Show consultation and prescription details.

## Patient record
24. Show medical history.

## Viva points
Controller → Service → Repository → Database; Spring Security; BCrypt; CSRF; appointment conflict validation; consultation completion; consultation-to-prescription relationship; patient-to-appointment/history relationships.
